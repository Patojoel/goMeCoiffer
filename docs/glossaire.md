# Glossaire métier — GoMeCoiffer

Vocabulaire du PRD, à employer **mot pour mot** dans les use cases et les écrans. La traduction dans le code
(anglais) est tenue par le skill `ddd` §1. Enrichi par `use-case-writer` à chaque nouveau terme.

| Terme                                                    | Définition                                                                                                                                                                                                             | Source           |
| -------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------- |
| Utilisateur                                              | Identité de connexion unique, qui peut appartenir à plusieurs salons.                                                                                                                                                 | PRD §3          |
| Organisation                                             | Entité propriétaire ou exploitante d'un ou plusieurs salons.                                                                                                                                                          | PRD §3          |
| Salon (établissement)                                   | Établissement physique rattaché à une organisation ; possède ses prestations, collaborateurs, horaires, réservations, paramètres et son abonnement.                                                               | PRD §3          |
| Collaborateur                                            | Utilisateur ayant une appartenance et des permissions dans un salon.                                                                                                                                                    | PRD §3          |
| Salon actif                                              | Salon sélectionné dans le back-office ; détermine le contexte d'autorisation.                                                                                                                                        | PRD §3          |
| Rôle système                                           | Super Administrateur, Administrateur Opérations, Administrateur Finance Plateforme ; attribués uniquement par GoMeCoiffer.                                                                                            | PRD §4          |
| Rôle salon                                              | Propriétaire, Administrateur de salon, Coiffeur/Barbier, Responsable financier, Praticien de beauté ; permissions ajustables par salon.                                                                               | PRD §5-6        |
| Intervenant (professionnel)                              | Personne qui réalise des prestations ; a des spécialités et des prestations autorisées.                                                                                                                             | PRD §5.5        |
| Spécialité                                             | Métier d'un intervenant (esthéticienne, manucure…) ; n'est pas un rôle de sécurité.                                                                                                                               | PRD §5.5        |
| Prestation                                               | Service proposé par un salon : nom, catégorie, prix, durée estimée, statut actif/inactif, description.                                                                                                              | PRD §7 étape 3 |
| Créneau                                                 | Intervalle de temps où une prestation peut être réalisée en entier par un intervenant.                                                                                                                              | PRD F02          |
| Disponible maintenant / Prochain créneau / Indisponible | États affichés d'un intervenant pour une prestation donnée.                                                                                                                                                          | PRD F02          |
| Blocage temporaire                                       | Indisponibilité déclarée par un professionnel, notamment pour un client sans réservation.                                                                                                                           | PRD F02, BR-07   |
| Réservation                                             | Rendez-vous pour une prestation assurée par un professionnel principal, dans un salon.                                                                                                                                 | PRD F03, §9     |
| « Peu importe »                                        | Choix du client qui laisse le système attribuer un professionnel qualifié et disponible.                                                                                                                              | PRD F03          |
| Client absent                                            | Client qui ne s'est pas présenté après le délai de tolérance.                                                                                                                                                      | PRD F06, BR-08   |
| Proposition de nouvel horaire (reprogrammation)          | Nouveau créneau proposé, acceptable ou refusable par lien, à durée de validité limitée ; une seule active par réservation.                                                                                       | PRD F06          |
| Paiement en ligne                                        | Paiement Mobile Money (Orange Money, MTN MoMo) via l'agrégateur, confirmé par le serveur.                                                                                                                             | PRD F04          |
| Paiement sur place                                       | Paiement au salon, déclaré par le responsable autorisé après encaissement.                                                                                                                                          | PRD F04          |
| Incident de paiement                                     | Paiement arrivé après expiration alors que le créneau n'est plus disponible ; à résoudre ou rembourser.                                                                                                            | PRD BR-06        |
| Publication                                              | Mise en ligne d'un salon dans la marketplace (au moins une prestation, un professionnel éligible, des horaires valides).                                                                                               | PRD §7 étape 7 |
| Abonnement                                               | Forfait SaaS mensuel ou annuel facturé par salon.                                                                                                                                                                      | PRD §10, F08    |
| Compte client léger                                     | Compte d'un client sans mot de passe, identifié par son numéro vérifié par code SMS ; il retrouve ses réservations à chaque vérification.                                                                        | D-018            |
| Compte propriétaire                                     | Compte d'un responsable de salon : numéro vérifié, mot de passe, sans rôle tant qu'il n'a pas créé son organisation.                                                                                              | UC-001           |
| Code de vérification (défi SMS)                        | Code à 6 chiffres envoyé par SMS pour prouver la possession d'un numéro ; valable 5 minutes, 5 essais, un seul actif par numéro et par motif (inscription, mot de passe oublié, invitation, vérification client). | D-017, UC-001    |
| Session                                                  | Période pendant laquelle un utilisateur est connecté sur un appareil ; s'ouvre à la connexion sans salon actif, se ferme à la déconnexion ou à expiration (inactivité, durée absolue).                          | D-004, UC-002    |
| Appareil reconnu                                         | Appareil sur lequel le titulaire d'un numéro s'est connecté avec succès récemment ; il échappe aux blocages de connexion visant les appareils inconnus.                                                            | UC-002           |
| Blocage de connexion                                     | Refus temporaire des connexions à un numéro (ou depuis une adresse réseau) après trop d'échecs, pour les appareils non reconnus ; levé par le temps ou « Mot de passe oublié ».                                | UC-002           |
| Numéro vérifié                                        | Numéro dont la possession a été prouvée par un code de vérification, avec la date de la preuve.                                                                                                                    | UC-001           |
| Réinitialisation du mot de passe (« Mot de passe oublié ») | Choix d'un nouveau mot de passe par un membre du personnel qui prouve la possession de son numéro par un code SMS ; ferme toutes ses sessions, lève les blocages de connexion du numéro et le reconnecte. | D-017, D-028, UC-003 |
| Version des identifiants                                 | Numéro de version du mot de passe d'un compte, augmenté à chaque réinitialisation ; une session ouverte avec une version antérieure ne donne plus accès.                                          | UC-003           |
| Période de grâce                                       | Délai après expiration de l'abonnement avant la suspension des nouvelles réservations publiques.                                                                                                                     | PRD F08          |
| Propriétaire | Rôle salon lié à la propriété de l'organisation : toutes les permissions du salon et des droits protégés, non désactivables ; donné à qui crée l'organisation, sur chacun de ses salons. | PRD §5.1, UC-004 |
| Appartenance | Lien entre un utilisateur et un salon, avec un rôle salon et un statut ; sans appartenance active, aucun accès au salon. | PRD §3, §11 |
| Nom commercial | Nom sous lequel le salon est connu des clients ; le nom de l'organisation reprend celui du premier salon. | PRD §7 étape 2, UC-004 |
| Type de salon | Salon de coiffure, barber shop, esthétique ou mixte ; un seul par salon. | PRD §7 étape 2 |
| Point de repère (adresse descriptive) | Indication pour trouver le salon (« face à la pharmacie du Centre »), en plus de la ville et du quartier. | PRD §7 étape 2 |
| Téléphone commercial | Numéro de contact du salon, distinct du numéro de connexion, non vérifié par SMS, affiché aux clients après la publication. | PRD §7 étape 2, UC-004 |
| Salon non publié | Salon créé et configurable dans le back-office, invisible dans la marketplace jusqu'à sa publication. | PRD F01, UC-004 |
| Onboarding | Mise en place guidée d'un salon, en étapes enregistrées une à une pour permettre une reprise. | PRD §7 |
| Ouvrir un salon (changer de salon) | Faire d'un salon où l'on a une appartenance active le salon actif de sa session ; à ne pas confondre avec l'ouverture du salon aux clients (horaires). | PRD §3, UC-005 |
| Contexte d'autorisation | Ce qu'un utilisateur peut voir et faire à un instant donné : les permissions de son rôle dans le salon actif, et rien d'un autre salon. | PRD §3, UC-005 |
| Liste de ses salons | Salons où l'utilisateur a une appartenance active, avec son rôle dans chacun ; c'est là qu'il choisit son salon actif. | PRD §3, UC-005 |
| Suivi en direct | Mise à jour automatique des écrans connectés (planning, disponibilités) ; il ne porte que le salon actif et se relit en entier à chaque reconnexion. | PRD F02, §12, UC-005 |
| Invitation (d'un collaborateur) | Proposition faite par un salon à une personne, désignée par son numéro, de rejoindre son équipe avec un rôle ; ne donne aucun accès avant d'être acceptée. États : en attente, acceptée, annulée, expirée. | PRD §7 étape 4, UC-006 |
| Rôle de collaborateur | Rôle salon que l'on peut donner par invitation : Administrateur de salon, Coiffeur / Coiffeuse / Barbier, Responsable financier, Praticien / Praticienne de beauté (jamais Propriétaire). | PRD §5, UC-006 |
| Compte du personnel | Compte avec mot de passe (propriétaire ou collaborateur) ; se connecte par numéro et mot de passe. S'oppose au compte client léger. | D-017, UC-001, UC-007 |
| Rejoindre un salon (accepter une invitation) | Action de la personne invitée : elle prouve son numéro par un code SMS, découvre le salon et le rôle, crée son compte si besoin ; son appartenance au salon est alors créée avec le rôle de l'invitation. | PRD §7 étape 4, UC-007 |
| Preuve du numéro | Résultat d'un code SMS juste pour rejoindre un salon : valable 15 minutes sur le seul navigateur où le code a été saisi ; n'ouvre aucune session, permet seulement de voir et d'accepter les invitations de ce numéro. | UC-007 |
| Espace client (« Mes réservations ») | Partie de la marketplace où le client retrouve ses réservations ; ouverte par une session client ou une session du personnel ; distincte de la vue « Mes rendez-vous » du professionnel dans le back-office. | PRD §13, F03, UC-009 |
| Session client | Session ouverte par un code SMS d'accès client : sans salon actif ni rôle, elle ne donne accès qu'à l'espace client, jamais au back-office ni à l'administration, même pour un membre du personnel. | D-018, UC-009 |
| Dernière preuve de possession du numéro | Dernier instant où le titulaire a prouvé posséder le numéro : code SMS juste (tout motif) ou connexion réussie par mot de passe. À ne pas confondre avec la « preuve du numéro » de UC-007. | UC-009 |
| Titulaire depuis (nouveau titulaire présumé) | Instant à partir duquel le titulaire actuel d'un numéro est présumé ; remis à zéro quand un code juste arrive après plus de 180 jours sans preuve (numéro recyclé par l'opérateur) ; l'espace client ne montre que les réservations faites depuis. | UC-009 (Q1) |
| Permission | Action autorisée dans un module du salon (« Finances : consulter », « Personnel : inviter »…) ; 17 au catalogue (PRD §6), évaluées dans le salon actif. | PRD §6, UC-008 |
| Permissions par défaut | Permissions données à chaque rôle de collaborateur à l'enregistrement d'un salon, avant tout réglage du propriétaire. | PRD §6, UC-008 |
| Rôles et permissions (réglage d'un rôle) | Écran « Paramètres → Rôles et permissions » où le propriétaire coche les permissions d'un rôle pour son salon ; le réglage vaut pour toutes les personnes de ce rôle dans ce salon, dès l'enregistrement. | PRD §6, UC-008 |
| Droits réservés au propriétaire | Droits qu'aucun autre rôle ne peut recevoir : Rôles et permissions : administrer, gérer les salons de l'organisation, gérer l'abonnement, gérer les comptes de règlement (destination des fonds). | PRD §5.1, §5.2, §6, UC-008 |
| Ajout d'un salon | Rattachement d'un nouvel établissement (2e, 3e…) à une organisation existante par son propriétaire, avec création atomique de son appartenance « Propriétaire » et des permissions par défaut des quatre rôles de collaborateur. | PRD §3, §5.1, D-041, UC-010 |
| Équipe du salon | Ensemble des utilisateurs disposant d'une appartenance active (`ACTIVE`) dans un salon, avec leur rôle dans ce salon. | PRD F07, UC-011 |
| Appartenance retirée (`REVOKED`) | État d'une appartenance lorsqu'un collaborateur est retiré de l'équipe : jamais supprimée (audit et historique conservés), coupe immédiatement l'accès et les flux en direct sur ce salon, sans toucher les autres salons du compte. | PRD F07, UC-011 |
| Réintégration (d'un collaborateur) | Retour dans l'équipe d'un collaborateur précédemment retiré : après une nouvelle invitation acceptée (UC-006, UC-007), sa même appartenance `(salon, utilisateur)` repasse de `REVOKED` à `ACTIVE` avec le nouveau rôle. | UC-011 |
| Super Administrateur | Rôle système de plus haut niveau : paramètres globaux, supervision, gestion des administrateurs GoMeCoiffer et suspension des salons ; au moins un reste toujours actif. | PRD §4, UC-012 |
| Administrateur Opérations | Rôle système dédié à la vérification des établissements, à l'assistance et à la supervision des réservations. | PRD §4, UC-012 |
| Administrateur Finance Plateforme | Rôle système dédié aux abonnements SaaS, à la facturation plateforme, aux commissions éventuelles et aux rapprochements financiers. | PRD §4, UC-012 |
| Attribution / retrait d'un rôle système | Action réservée à un Super Administrateur (hors soi-même) pour donner ou retirer un rôle système à un compte du personnel existant ; le retrait ferme immédiatement toutes les sessions et flux en direct de la personne. | PRD §4, §13, UC-012 |
| Initialisation du premier Super Administrateur | Commande d'exploitation exécutée hors HTTP par l'exploitant GoMeCoiffer pour attribuer le premier rôle Super Administrateur à un compte du personnel existant (idempotente). | UC-012 |
